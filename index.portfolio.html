08 // acessibilidade

Declaração de acessibilidade

Este site foi construído para ser usado por todas as pessoas — com ou sem deficiência — e é também a vitrine do padrão que aplico em todos os projetos que entrego.

👁

Para quem tem deficiência visual

Compatível com leitores de tela (NVDA, JAWS, TalkBack, VoiceOver): estrutura semântica, textos alternativos, regiões nomeadas e anúncios de mudanças de estado. Alto contraste, tema claro/escuro, ajuste de tamanho de texto e espaçamentos, fonte para baixa visão e leitura em voz alta integrada.

🤟

Para quem tem deficiência auditiva

Tradução para Libras em qualquer trecho do site pelo VLibras (Governo Federal) — basta usar o botão azul de mãos na lateral. Todo o conteúdo é textual: nenhuma informação depende de áudio. Vídeos futuros terão legendas e transcrição.

⌨

Para quem navega só pelo teclado

Todas as funções acessíveis por teclado, com foco sempre visível, atalhos padronizados eMAG e sem armadilhas de foco. Animações podem ser pausadas e a preferência do sistema por movimento reduzido é respeitada.

Atalhos de teclado

  • Alt + 1 Ir para o conteúdo
  • Alt + 2 Ir para o menu
  • Alt + 3 Ir para o contato
  • Alt + 4 Ir para o rodapé
  • Alt + 0 Abrir painel de acessibilidade

No Windows use Alt + número (no Firefox, Alt + Shift + número); no Mac, Control + Option + número.

Meta de conformidade: eMAG 3.1 e WCAG 2.1 nível AA. Encontrou uma barreira? Me avise pelo WhatsApp ou email — corrigir é prioridade.
